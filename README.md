# Room Calendar version notices

This public repository contains version metadata for Room Calendar. It contains no application source, installers, credentials, room bookings or user data.

[Download and install Room Calendar from GitHub](https://github.com/camster91/Rcalendar/releases/latest). Access to the private Rcalendar repository is required to download its installers.

The app checks this public feed without a GitHub token. A newer version shows a notice linking to the Rcalendar releases page. Installation is handled in your browser.
